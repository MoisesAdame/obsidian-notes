## Administración de Proyectos 
### Definición de Administración
#Q 
- En el proceso de :: Lograr que las cosas se hagan.
- Utilizando cosas como :: Organización, delegación, planeación, etc.

### Definición de Proyecto
#Q 
- Definición formal :: Esfuerzo **temporal** para crear **producto o servicio**.
- Un **proyecto** tiene bien definido un..., es un conjunto de tareas..., usa varios... no solo... tiene un... e involucra cierto... :: Objetivo, definidas, recursos, humanos, cliente/usuario, riesgo.
- Un ejemplo de algo que **no** es proyecto son las... porque no tienen... :: Operaciones, fin.

### Planeación y Diseño de Proyectos
#Q 
- Es un error decir cosas como :: Quiero implementar AI. Quiero usar este rack.
1. Primero se **definen** los :: Requerimientos.
2. Los **requerimientos** definen :: Performance (Rendimiento).
3. El **rendimiento** define la :: Tecnología.
4. La **tecnología** define :: Marca/Producto.

### Project Management
#Q 
- La preocupación principal del PM es que :: El triángulo de **costo**, **tiempo** y **alcance** este balanceado.
- Si ese triángulo está balanceado :: El proyecto está en buen estado.

### Procesos de la Administración de Proyectos
#Q 
- Las **5 partes** de administración de proyectos son :: Inicio, planeación, ejecución, monitoreo y control y cierre.
