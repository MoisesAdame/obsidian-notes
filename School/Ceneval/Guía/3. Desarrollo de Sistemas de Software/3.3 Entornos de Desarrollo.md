## Qué es un IDE?
#Q 
- Es un **software** que se forma por un... orientadas al... :: Conjunto de herramientas, desarrollo de software.

## Objetivos
#Q 
- Buscan **maximizar** la :: Productividad del programador.
- Nos dan un solo software donde :: Hacemos todo.
- Buscan **reducir** la cantidad de :: Configuración.
- Los IDE's dedicados a un **lenguaje específico** buscan para ese lenguaje :: Darnos **features** específicas.

## Componentes
#Q 
- Sus **6 principales** componentes son :: Editor de texto, compilador, intérprete, depurador, constructor de interfaz gráfica, control de versiones.

### Editor de Texto
#Q 
- Lugar donde se **escribe** el :: Código fuente.

### Compilador e Intérprete
#Q 
- **Compilador** traduce código fuente a... y crea... :: Código máquina, ejecutable.
- **Intérprete** durante el... traduce y... el código :: Runtime, ejecuta.
- El **intérprete** ejecuta el código :: Línea a línea.
- Usar **compilador** cuando se busca... y usar **intérprete** cuando se busca... :: Performance, flexibilidad.

### Depurador (Debugger)
#Q 
- Sirve para limpiar al código de :: Errores.
- Permite que en cualquier punto se :: Detenga el código.

### Constructor de Interfaz Gráfica
#Q 
- Sirve para **crear y ver** la :: GUI.

### Control de Versiones
#Q 
- Se encarga de **controlar** los... realizados en las aplicaciones :: Cambios.
