## Paradigmas de Programación 
### Introducción
#Q 
- Son **diferentes maneras** de :: Escribir código.
- La forma en que los programas se escriben es :: Influenciada por los **paradigmas**.
- Se dividen en **2 grandes grupos** que son :: Imperativos y declarativos.

### Paradigmas Imperativos
#Q 
- Le dicen a la computadora :: La **forma (receta)** para hacer algo.
- Los **3 tipos** de lenguajes imperativos son :: OOP, procedural y estructurado.

#### Programación Orientada a Objetos
#Q 
- Organiza el código en... los cuales encapsulan cosas como... y... :: Objetos, datos, comportamiento.
- Sus **4 características principales** son :: Abstracción, encapsulamiento, polimorfismo y herencia.
- **Encapsulamiento** almacena en el objeto cosas como... y... su ventaja es que la información en la DB no puede ser... :: Datos, funcionalidad, alterada.
- **Abstracción** estandariza cosas como la... y sirve para que el programa sea... :: Lógica de negocio, escalable.
- **Herencia** permite que un objeto :: Herede **aspectos** de otro.
- **Polimorfismo** según el objeto es el :: Comportamiento.

#### Programación Procedural
#Q 
- El código lo estructura en :: Funciones.
- Mediante las **funciones** logra que el código sea :: Reusable.

#### Programación Estructurada
#Q 
- Organiza el código en cosas como :: Estructuras de control y loops.
- Es bueno para cosas como la... y la... :: Legibilidad, mantenibilidad.

### Paradigmas Declarativos
#Q 
- Se enfoca en el... mas que en como... :: Resultado, obtenerlo.
- Un muy buen **ejemplo** de este tipo de lenguajes es :: SQL.
- Los **2 tipos** de programación declarativa son :: Funcional y lógica.
