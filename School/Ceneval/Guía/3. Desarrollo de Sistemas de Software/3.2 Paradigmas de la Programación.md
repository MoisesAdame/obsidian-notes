## Paradigmas de Programación 
### Introducción
#Q  #AOSR/7fel3
- Son **diferentes maneras** de :: Escribir código. #AOSR/7fel3/s/355k
- La forma en que los programas se escriben es :: Influenciada por los **paradigmas**. #AOSR/7fel3/s/6l54
- Se dividen en **2 grandes grupos** que son :: Imperativos y declarativos. #AOSR/7fel3/s/351f

### Paradigmas Imperativos
#Q  #AOSR/1d70i
- Le dicen a la computadora :: La **forma (receta)** para hacer algo. #AOSR/1d70i/s/1l1p
- Los **3 tipos** de lenguajes imperativos son :: OOP, procedural y estructurado. #AOSR/1d70i/s/3hup

#### Programación Orientada a Objetos
#Q  #AOSR/6947o
- Organiza el código en... los cuales encapsulan cosas como... y... :: Objetos, datos, comportamiento. #AOSR/6947o/s/1r2v
- Sus **4 características principales** son :: Abstracción, encapsulamiento, polimorfismo y herencia. #AOSR/6947o/s/3php
- **Encapsulamiento** almacena en el objeto cosas como... y... su ventaja es que la información en la DB no puede ser... :: Datos, funcionalidad, alterada. #AOSR/6947o/s/7t34
- **Abstracción** estandariza cosas como la... y sirve para que el programa sea... :: Lógica de negocio, escalable. #AOSR/6947o/s/361l
- **Herencia** permite que un objeto :: Herede **aspectos** de otro. #AOSR/6947o/s/z635
- **Polimorfismo** según el objeto es el :: Comportamiento. #AOSR/6947o/s/79hn

#### Programación Procedural
#Q  #AOSR/4f5mn
- El código lo estructura en :: Funciones. #AOSR/4f5mn/s/apvo
- Mediante las **funciones** logra que el código sea :: Reusable. #AOSR/4f5mn/s/2bq7

#### Programación Estructurada
#Q  #AOSR/ffuis
- Organiza el código en cosas como :: Estructuras de control y loops. #AOSR/ffuis/s/7jdb
- **Bueno** para cosas como la... y la... :: Legibilidad, mantenibilidad. #AOSR/ffuis/s/1jbe

### Paradigmas Declarativos
#Q  #AOSR/4id6s
- Se enfoca en el... mas que en como... :: Resultado, obtenerlo. #AOSR/4id6s/s/2roe
- Un muy buen **ejemplo** de este tipo de lenguajes es :: SQL. #AOSR/4id6s/s/3s09
- Los **2 tipos** de programación declarativa son :: Funcional y lógica. #AOSR/4id6s/s/55a4

#### Programación Funcional
#Q #AOSR/2mfof
- Ve la programación como la evaluación de :: Funciones matemáticas. #AOSR/2mfof/s/6d4g
- A los **datos mutables** los evita :: Cambiar. #AOSR/2mfof/s/1u57
- Un concepto muy importante es :: La **recursividad**. #AOSR/2mfof/s/548f

#### Programación Lógica
#Q  #AOSR/z5634

- Se basa en **relaciones** :: Lógicas. #AOSR/z5634/s/7aaq
- Ejemplo de **lenguaje** :: Prolog. #AOSR/z5634/s/2r1c
