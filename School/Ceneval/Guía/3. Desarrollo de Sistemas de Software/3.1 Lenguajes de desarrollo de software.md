## Lenguajes de Programación
### Definición
#Q 
- Es un **formalismo artificial** en el que se pueden expresar :: Algoritmos.
- Es un conjunto de... que permiten asociar a cada programa correcto un... :: Reglas, cálculo.
- No tienen :: Ambigüedades.

### Niveles de Descripción
#Q 
- Un lenguaje se puede describir en **3 áreas** que son :: Gramática, semántica y pragmática.
- En computación hay un **4to nivel** que es :: Implementación.

#### Gramática
#Q 
- Responde a la **pregunta** :: Qué frases son correctas.
- Necesita un **alfabeto $\sum$** que es un :: Conjunto *finito* de *símbolos*.
- Necesita un **componente léxico** que nos dice que :: Secuencia de símbolos forman **tokens**.
- Necesita una **sintaxis** que nos dice la secuencia de :: Palabras que hacen *frases legales*.

#### Semántica
#Q 
- A cada frase correcta le da :: Un significado.

#### Pragmática
#Q 
- A una frase con significado le da :: Un uso.

#### Implementación
#Q 
- Tenemos que **describir** como ejecutar una... de tal modo que respete... :: Oración correcta, semántica.
