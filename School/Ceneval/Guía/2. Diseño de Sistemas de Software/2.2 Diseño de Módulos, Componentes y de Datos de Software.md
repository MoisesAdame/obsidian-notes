## Diagramas UML 
#Q 
- UML es un... que sirve para... sistemas de sw. :: Lenguaje, documentar
- Tiene **2 tipos** de diagramas :: Estructurales y de comportamiento.
- Los diagramas **estructurales** son los que modelan :: Las cosas (clases, objetos, interfaces, componentes físicos, etc.)
- Los diagramas **de comportamiento** nos dicen como el sistema :: Va a actuar.

### Diagramas Estructurales
#### Diagramas de Estados
#Q 
- Modela aspectos del sistema que son :: Dinámicos.
- Solo se construye para objetos :: Reactivos.
- Tiene **3 componentes** que son :: Estados, compuertas y transiciones.
- Ejemplo ATM :: ![state-diagram-atm|300](https://media.geeksforgeeks.org/wp-content/uploads/20200618233359/Untitled641.png)

#### Diagrama de Clases
#Q 
- Muestra las... del sistema y su... :: Clases, relación.
- En la visibilidad tenemos **3 estados** :: Público (+), privado (-) y protegido (#).
- La diferencia entre **privado** y **protegido** es que :: Los atributos o métodos protegidos se **heredan** mientras que los privados no.
- Representación de **herencia** :: ![inheritance-represenation](https://cdn-images.visual-paradigm.com/guide/uml/what-is-class-diagram/03-inheritance.png)
- Representación de **asociación simple** :: ![simple-assosiation-representation](https://cdn-images.visual-paradigm.com/guide/uml/what-is-class-diagram/04-simple-association.png)
- Representación de la **agregación** :: ![agregation-representation](https://cdn-images.visual-paradigm.com/guide/uml/what-is-class-diagram/05-aggregation.png)
- Representación de la **composición** :: ![composition-representation](https://cdn-images.visual-paradigm.com/guide/uml/what-is-class-diagram/06-composition.png)
- Representación de la **dependencia** :: ![dependency-representation](https://cdn-images.visual-paradigm.com/guide/uml/what-is-class-diagram/07-dependency.png)
- La **agregación** significa que :: Una clase pertenece a otra.
- El diagrama de **agregación** se lee :: Class2 es parte de Clase 1.
- La **composición** significa que cuando :: El padre muere, el hijo también.
- La dependencia significa que los... de una clase pueden provocar... :: Cambios, cambios en la otra.
- Ejemplo ATM :: ![class-diagram-atm|300](https://images.wondershare.com/edrawmax/templates/class-diagram-for-atm.png)

#### Diagrama de Objetos
#Q 
- Se enfoca en los... de un conjunto de objetos y su... :: Atributos, relación.
- Son un... de los diagramas de clases :: Caso especial.
- Usan un subconjunto de los... con el fin de enfatizar su relación en un... :: Elementos del diagrama de clases, momento específico.
- Ejemplo ATM :: ![object-diagram-atm|300](https://www.researchgate.net/publication/303565353/figure/fig8/AS:667900482433024@1536251292048/ATM-systems-object-diagram.ppm)

### Diagramas de Comportamiento
#### Diagrama de Secuencia.
#Q 
- Muestran como los objetos a lo largo del tiempo :: Intercambian mensajes.
- En el eje de las x son los... y en el de las y es ... :: Objetos, tiempo.
