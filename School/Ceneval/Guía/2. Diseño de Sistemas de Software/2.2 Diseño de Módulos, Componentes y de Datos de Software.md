## Modelo "4+1" Vistas de Kruchten

#Q 
- Encaja con el estándar :: IEEE 1471-2000
- Se usa para describir la... de un sistema de sw. basado en múltiples... :: Arquitectura, puntos de vista.

### Vistas "4+1"
#Q 
- Las **4+1 vistas** son :: Lógica, de procesos, de despliegue, física y +1.
- La función de la **vista +1** es :: Relacionar las 4 vistas.
- El otro nombre de la **vista +1** es :: Vista de escenario.

### Vista Lógica
#Q 
- Representa la... que se les dará a los... :: Funcionalidad, usuarios finales.

#Q

#Q

## Bases de Datos
### Introducción
#Q 
- Una DB es una recopilación de datos :: Organizada y estructurada.
- Un DBMS o SGBD es una app que puede estar alojado en :: Local o en la nube.
- Nos sirve para ejecutar :: Comandos u operaciones.

### Data Base Management System
#### Clasificación
#Q 
- Los **3 criterios** bajo los cuales se pueden clasificar los DBMS son :: Modelado de datos, usuarios soportados y distribución.

##### DBMS por Modelado de Datos
#Q 
- Se usa en la mayoría de las DBMS :: Comerciales.
- Son :: Relacional, objetos, objeto-relacional, jerárquico y de red.
- Característica del **modelo jerárquico** es que no hay nodo con :: Múltiples padres.
- Característica del **modelo de redes** es cada nodo tiene :: Múltiples padres.
- Característica del **modelo orientado a objetos** es que los datos se guardan como... además considera aspectos de... y hasta se pueden definir cosas como... :: Objetos, OOP, funciones.
- Característica del **modelo relacional** los datos se representan como :: Tablas.

##### DBMS por Usuarios Soportados
#Q 
- Hay **2 tipos** :: Monousuario y multiusuario.

##### DBMS por Distribución de la Base de Datos
#Q 
- Hay **2 tipos** :: Centralizado y distribuido.
- La diferencia es que :: El **centralizado** está en 1 computadora, el distribuido en 2 o más.

### Modelo Relacional: Definiciones
#Q 
- Nombre formal de la tabla :: Relación.
- Nombres formales de las columnas :: Atributos o campos.
- Nombre formal de las filas :: Tuplas.
- Número de atributos en relación :: Degree.
- Número de tuplas en relación :: Cardinalidad.
- Una relación con nombre definida por un conjunto de atributos y pares de nombre de dominio es :: Relation Schema (Esquema de la Relación).
- Un conjunto de **esquemas de relación** cada uno con un nombre distinto es :: Relational DB Schema (Esquema de DB relacional)
- Los **4 tipos de keys** son :: Candidate, foreign, primary y super.
- **Candidate keys** son :: El conjunto mínimo de atributos que pueden de forma *única* identificar a una tupla.
- **Primary key** es la :: Candidate key elegida.
- **Foreign key** es la :: Primary key de otra relación.
- **Super key** es es el conjunto de todas las llaves que pueden de forma... identificar... :: Única, cada tupla de la relación.
- Las candidate keys son un subconjunto de las :: Super keys.
- La información en un momento x en la base de datos se llama :: Snapshot.

### Arquitectura de Esquema Triple e Independencia de Datos
#### Las 3 Características del Enfoque de las Bases de Datos
#Q 
1. Los programas y los datos deben estar :: Aislados.
2. Soporte de múltiples :: Vistas de usuario.
3. Para almacenar la descripción de la DB se usa un :: Catálogo.

- Para satisfacer estas 3 características se utilizó la :: Arquitectura de Esquema triple.
- La **independencia de datos** se entiende como que cuando cambias el esquema en un nivel :: No es necesario cambiar el siguiente nivel.
- Los **2 tipos de independencia** de datos son :: Lógica y física.
- La **independencia lógica** es que al cambiar el esquema... no sea necesario cambiar el esquema... :: Conceptual, externo.
- La **independencia física** es que al cambiar el esquema... no sea necesario cambiar el esquema... :: Interno, conceptual.

#### Arquitectura de Esquema Triple
#Q 
- Los **3 niveles** son :: Nivel Interno, nivel conceptual y nivel externo.
- El **nivel interno** describe la estructura del almacenamiento... y por ello usa un modelo de datos... :: Físico, físico.
- El **nivel conceptual** tiene un esquema... y se enfoca en el ocultar detalles del almacenamiento... :: Conceptual, físico.
- El **nivel externo** incluye diferentes... :: Vistas de usuario.

### Lenguajes e Interfaces de Bases de Datos
#### Structured Query Language (SQL)
#Q 
- SQL es un lenguaje que consta de diferentes declaraciones las cuales pueden clasificarse a su vez en :: Sublenguajes.
- Los **5 sublenguajes** de SQL son :: Data Definition Language (DDL), Data Manipulation Language (DML), Data Query Language (DQL), Data Control Language (DCL) y Transactional Control Language (TCL).
- El **DDL** manipula..., ejemplos de comandos... :: Tablas, `CREATE`, `ALTER` y `DROP`
- El **DML** manipula... , ejemplos de comandos... :: Datos, `INSERT`, `UPDATE`, `DELETE`, `MERGE`
- El **DQL** debido a que manipula... algunos lo consideran..., ejemplos de comandos... :: Datos, DML, `SELECT`.
- Del **DCL** ejemplos de comandos :: `GRANT` y `REVOKE`.
- Del **TCL** ejemplos de comandos :: `COMMIT`, `ROLL BACK`, etc.
