## Modelo "4+1" Vistas de Kruchten
### Introducción
#Q 
- Encaja con el estándar :: IEEE 1471-2000
- Se usa para describir la... de un sistema de sw. basado en múltiples... :: Arquitectura, puntos de vista.
- Una **vista** nos deja ver todo el sistema desde una :: Perspectiva determinada.

### Vistas "4+1"
#Q 
- Las **4+1 vistas** son :: Lógica, de procesos, de despliegue, física y +1.
- La función de la **vista +1** es :: Relacionar las 4 vistas.
- El otro nombre de la **vista +1** es :: Vista de escenario.

### Vista Lógica
#Q 
- Representa la... que se les dará a los... :: Funcionalidad, usuarios finales.
- Algunos de los diagramas que usa :: De clases, de comunicación y de secuencia.

### Vista de Despliegue
#Q 
- Se da la perspectiva de un :: Programador.
- Se encarga de la :: Gestión de softare.
- Muestra como el sistema está divido en :: Componentes.
- Diagramas que usa :: Diagrama de componentes, diagrama de paguetes.

### Vista de Procesos
#Q 
- Muestra los... del sistema y la... entre ellos :: Procesos, comunicación.
- Da la perspectiva de un :: Integrador de sistemas.
- Diagramas que usa :: Diagrama de actividad.

### Vista Física
#Q 
- Nos da la perspectiva de un :: Ingeniero de sistemas.
- Nos habla de todos los... físicos así como sus... :: Componentes, conexiones.
- Diagrama que usa :: Diagrama de despliegue.

### "+1" Vista de Escenarios
#Q 
- Su función es :: Unir y relacionar las 4 vistas.
- También sirve para tener cierta :: Trazabilidad
- Diagrama que usa :: Diagrama de casos de uso.
