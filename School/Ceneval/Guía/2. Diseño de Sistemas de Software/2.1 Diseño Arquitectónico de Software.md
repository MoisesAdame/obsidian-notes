## Diseño Arquitectónico del Software
### Diseño y Arquitectura
#### Arquitectura de Software
#Q 
- La arquitectura del sw. es la :: Estructura del sistema
- Comprende cosas como sus... propiedades que son... y las... :: Elementos, visibles externamente, relaciones.
- Un **elemento** de la arquitectura de sw. es una pieza... a partir de la cual se puede construir un... :: Fundamental, sistema.
- Un **stakeholder** es aquel persona grupo o interés que tiene... sobre la realización de la arquitectura :: Interés.
- Una **preocupación** de la arquitectura es un... que se quiere que la arquitectura cumpla :: Objetivo.

#### Stakeholders
#Q 
- Los stakeholders pueden ser desde... hasta... :: Developers, clientes.
- Los **users** son los que definen la :: Funcionalidad.
- Los **testers** son los que al sistema lo :: Prueban.
- Los **suppliers** son los que construyen hw., sw. o infraestructura sobre la que se :: Ejecutará el sistema.
- Los **developers** son los que al sistema lo :: Construyen e implementan.

#### Software Design Description (SDD)
#Q 
- Son el conjunto de **artefactos** encargados de :: Documentar la arquitectura.
- Sirve para que los **involucrados** puedan :: Entender la arquitectura.
- No es posible capturar **toda** la arquitectura en :: Un solo artefacto.
- Para capturar toda la arquitectura hay que usar un conjunto de :: Vistas interrelacionadas.
- Según el stakeholder es el... o... que le mostraremos :: Artefacto, vista.

#### Arquitectural Views
#Q 
- Una vista es una representación de uno o mas aspectos... de la arquitectura :: Estructurales.
- Al diseñarla hay que ser claro en los..., por eso se creo... :: Detalles, UML.

#### Architectural Viewpoints
#Q 
- Son el conjunto de patrones, machotes y convenciones que sirven para construir un :: Tipo de vista.
- Según el **stakeholder**, en la perspectiva se deben ver sus :: Preocupaciones.
- El **contexto** es la relación entre... y... :: Sistema, ambiente.
- Lo **funcional** es la descripción de lo que el sistema :: Debe hacer.
- La **información** es la forma en que la arquitectura :: Maneja la información.
- La **concurrencia** es todo aquello en el sistema que puede :: Ejecutar de forma paralela.
- El **desarrollo** es la arquitectura que soporta el :: Desarrollo de sw.
- El **despliegue** es el... en el que el sistema se va a... :: Ambiente, implementar.
- El **operacional** es como se le va a dar..., como se va a... y... el sistema :: Soporte, administrar, operar.
