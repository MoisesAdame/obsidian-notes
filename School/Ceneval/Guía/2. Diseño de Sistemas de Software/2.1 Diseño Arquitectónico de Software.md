#### Architectural Viewpoints
#Q  #AOSR/enhp7
- Son el conjunto de patrones, machotes y convenciones que sirven para construir un :: Tipo de vista. #AOSR/enhp7/s/2rtd
- Analógicamente, para las views, los viewpoints representan los :: Planos #AOSR/enhp7/s/7vhk
- Según el **stakeholder**, en la perspectiva se deben ver sus :: Preocupaciones. #AOSR/enhp7/s/9d9b
- Algunos de los **principales tipos** de viewpoints son :: Contextual, de información, de concurrencia, de desarrollo, de despliegue, operacional. #AOSR/enhp7/s/7u4c
- El **contexto** es la relación entre... y... :: Sistema, ambiente. #AOSR/enhp7/s/628r
- La **información** es la forma en que la arquitectura :: Maneja la información. #AOSR/enhp7/s/inh0
- La **concurrencia** es todo aquello en el sistema que puede :: Ejecutar de forma paralela. #AOSR/enhp7/s/2smj
- El **desarrollo** es la arquitectura que soporta el :: Desarrollo de sw. #AOSR/enhp7/s/56b8
- El **despliegue** es el... en el que el sistema se va a... :: Ambiente, implementar. #AOSR/enhp7/s/1j2d
- El **operacional** es como se le va a dar..., como se va a... y... el sistema :: Soporte, administrar, operar. #AOSR/enhp7/s/40tn

#### Architectural Perspectives
#Q  #AOSR/3o8l4
- Son la colección de actividades, tácticas y lineamientos que se usan para asegurar que el sistema tiene :: Calidad. #AOSR/3o8l4/s/3g0q
- Generalmente abordan problemas relacionados a :: Requerimientos no funcionales. #AOSR/3o8l4/s/25it
- Algunas de los **principales tipos** de perspectivas arquitectónicas son :: Accesibilidad, evolución, internacionalización, seguridad, performance y escalabilidad. #AOSR/3o8l4/s/4qkc
- La **accesibilidad** es que pueda ser usado por :: Discapacitados. #AOSR/3o8l4/s/5fch
- La **evolución** es que sea flexible a :: Cambios. #AOSR/3o8l4/s/6icd
- La **internacionalización** es que esté en diferentes :: Lenguajes. #AOSR/3o8l4/s/64ag
- El **performance y escalabilidad** es que se pueda adaptar a mayores :: Volúmenes de procesamiento. #AOSR/3o8l4/s/4tj6
- La **seguridad** es quien puede :: Hacer que. #AOSR/3o8l4/s/5s8a

### Patrones de Diseño
#### Introducción
#Q  #AOSR/hr4q3
- Son una forma... de resolver un problema... :: Reutilizable, común. #AOSR/hr4q3/s/10ri
- A la solución de algunos problemas la :: Estandarizan. #AOSR/hr4q3/s/1c7o
- Definen entre los desarrolladores un :: Lenguaje común. #AOSR/hr4q3/s/65k6
- Ahorran... y aseguran la... :: Tiempo, calidad. #AOSR/hr4q3/s/1fsl
- Este concepto fue inicialmente descrito en el libro... del autor... :: El Lenguaje de Patrones, Christopher Alexander. #AOSR/hr4q3/s/3rf6
- Quienes usan por primera vez este concepto en el desarrollo de software son los autores :: Erich Gamma, Richard Helm, Ralph Johnson y John Vlissides #AOSR/hr4q3/s/6n3s
