## 4 Gestión de Proyectos de Software
#Q  #AOSR/42bp8
- **ISO/IEC 9126** :: Identifica y nos ayuda a cumplir con los **6 atributos** de la calidad de software. #AOSR/42bp8/s/2d86
- **IEEE 730** :: Requisitos mínimos para SQA y guía para SQAP. #AOSR/42bp8/s/3nn5
- **IEEE 1028** :: Define cinco tipos de revisiones y auditorías de software, junto con los procedimientos necesarios para su ejecución. #AOSR/42bp8/s/4cuc
- **ISO 9000** :: Estándar generalista de calidad. #AOSR/42bp8/s/2eli
- **ISO 12207** :: Modelos de Ciclo de Vida de Software. #AOSR/42bp8/s/377o
- **ISO/IEC 14598** :: Mediciones y evaluaciones de la calidad de producto de software. #AOSR/42bp8/s/15fr
- **ISO/IEC 25000** :: **S**ystem and **S**oftware **Qua**lity **R**equierements and **E**valuation (**SQUARE**). Junta ISO/IEC 9126 e ISO/IEC 14598. #AOSR/42bp8/s/4a2m
- **ISO/IEC 15504** :: **S**oftware **P**rocess **I**mprovement and **C**apability d**E**termination (**SPICE**). Busca mejorar los procesos de software mediante su evaluación. #AOSR/42bp8/s/76sp
- **CMMI** :: **C**apability **M**aturity **M**odel **I**ntegration (**CMMI**). Busca mejorar procesos de software mediante su evaluación. #AOSR/42bp8/s/1lnv
- **TSP** :: Team Software Development Process. Tiene roles y usa información de PSP para generar mediciones. #AOSR/42bp8/s/3i81
- **PSP** :: Personal Software Development Process. Es de uso personal, le da disciplina a ingeniero mejorando la calidad de sus productos. #AOSR/42bp8/s/4e7i
- **MoProSoft** :: **Mo**delo de **Pro**cesos para la Industria de **Soft**ware. Como SPICE o CMMI pero para PyMEs. #AOSR/42bp8/s/1vka
- **ISO/IEC 29110** :: Perfiles del Ciclo de Vida para Entidades muy Pequeñas. MoProSoft pero con reconocimiento internacional. #AOSR/42bp8/s/5s6c
- **ISO/IEC 33000** :: Actualización de ISO/IEC 15504. Mas flexible y moderno. #AOSR/42bp8/s/42j8
