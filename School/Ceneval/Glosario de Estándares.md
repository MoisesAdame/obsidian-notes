## 4 Gestión de Proyectos de Software
#Q 
- **ISO/IEC 9126** :: Identifica y nos ayuda a cumplir con los **6 atributos** de la calidad de software.
- **IEEE 730** :: Requisitos mínimos para SQA y guía para SQAP.
- **IEEE 1028** :: Define cinco tipos de revisiones y auditorías de software, junto con los procedimientos necesarios para su ejecución.
- **ISO 9000** :: Estándar generalista de calidad.
- **ISO 12207** :: Modelos de Ciclo de Vida de Software.
- **ISO/IEC 14598** :: Mediciones y evaluaciones de la calidad de producto de software.
- **ISO/IEC 25000** :: **S**ystem and **S**oftware **Qua**lity **R**equierements and **E**valuation (**SQUARE**). Junta ISO/IEC 9126 e ISO/IEC 14598.
- **ISO/IEC 15504** :: **S**oftware **P**rocess **I**mprovement and **C**apability d**E**termination (**SPICE**). Busca mejorar los procesos de software mediante su evaluación.
- **CMMI** :: **C**apability **M**aturity **M**odel **I**ntegration (**CMMI**). Busca mejorar procesos de software mediante su evaluación.
- **TSP** :: Team Software Development Process. Tiene roles y usa información de PSP para generar mediciones.
- **PSP** :: Personal Software Development Process. Es de uso personal, le da disciplina a ingeniero mejorando la calidad de sus productos.
- **MoProSoft** :: **Mo**delo de **Pro**cesos para la Industria de **Soft**ware. Como SPICE o CMMI pero para PyMEs.
- **ISO/IEC 29110** :: Perfiles del Ciclo de Vida para Entidades muy Pequeñas. MoProSoft pero con reconocimiento internacional.
- **ISO/IEC 33000** :: Actualización de ISO/IEC 15504. Mas flexible y moderno.
