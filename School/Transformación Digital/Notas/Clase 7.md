## Módulo Cloud
### Módulo 3: Datos
#### Datos
- Los números y las letras no son datos.
- Los datos **no son útiles** si no tengo el contexto

```
John Doe 83
```

- No se si es un nombre, nombre de calle, edad, año, etc.
- Conforme agrego contexto a los datos, los datos aumentan.

- Datos: Hechos, piezas de información.
- Datasets: Datos organizados.
- Metadada: Información sobre la información.

#### The Lego Data Activity
- El color también aporta el contexto.
- Por el gran poder computacional, cada vez se le agrega mas contexto a la información. Pero esto es mas **costoso**.

#### Tipos de Datos
- Cuantitativos: Contables o medibles.
- Cualitativos

#### Data Driven
- Toma decisiones basadas en datos.
- No solo es tener **muchos datos**, si no que puedes responder **cómo** y **por qué** para tomar decisiones.

#### Los datos ahora
- Se estan generando una gran variedad, velocidad y volumen.
- Esto solo es posible a través de la nube.
