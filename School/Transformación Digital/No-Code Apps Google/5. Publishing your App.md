## App Deployment Process
Pasos para deployear un app:
1. Hacer checkeo de deployment
2. Resolver errores
3. Deploy app.
4. Testear app como usuario.
Para realizar **checkeo de deployment** ir a Manage > Deploy > Deployment Check
Una vez que se resolvieron los errores mover a **deployment state**. Si es necesario también es posible **undeploy** la aplicación.
Tipos de deployment:
- Intant
- Traditional
Para **testear la app** usar la aplicación **App Gallery**.

## Deployment Methods
Instant deployment: Es como si el app fuera una página web, pero antes necesita descargar el app de **AppSheet Host**. Es buena porque se actualiza de forma automática.
Traditional deployment: Si queremos que se consuma a gran escala el App.
- Crear white-label (Manage > Deploy > White Label)
- Subir paquete a la AppStore
- Esperar a que la AppStore la apruebe.

## Testing the App
La forma más fácil es primero usando la **AppSheet Hosting App**.
