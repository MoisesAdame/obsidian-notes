## Teoría de la Probabilidad 
### Definiciones Básicas
#Q 
- **Probabilidad** nos permite... que tan... en un... :: Determinar, posible es algo, entorno.
- **Variables independientes** son los valores que :: No dependen de otro.
- **Variables dependientes** son valores que son... por... :: Afectados, otros valores.
- **Muestreo** proceso de obtener un conjunto de... de una... :: Observaciones, población.

### Variables Aleatorias
#Q 
- Define una **variable aleatoria** de manera formal :: Sea $S$ un espacio muestral sobre el cual se encuentra definida una función de probabilidad. Sea $X$ una función de valor real definida sobre $S$ tal que transforme los resultados de $S$ en una cantidad numérica. Una variable $X$ es una variable aleatoria si el valor que asume, de acuerdo con el resultado de un experimento, es un evento aleatorio.
