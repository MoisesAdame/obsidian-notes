## Fragmentación
### Reglas de Fragmentación
#Q  #AOSR/3b7e2
- Cuales son :: Completitud, disyunción y reconstrucción. #AOSR/3b7e2/s/6se3

### Tipos de Fragmentación
#Q 
- Cuales son :: Vertical, horizontal y Mixta.

### Reglas de Fragmentación para Fragmentación Horizontal
#Q
1. Regla de Completitud :: $R = R_{1} \cup R_{2} \cup \cdots \cup R_{n}$
2. Regla de Disyunción :: $\forall 1 \le i \neq j \le n : R_{1} \cap R_{2} = \varnothing$
3. Regla de Reconstrucción :: $R = \bigcup_{1\le i \le n}R_{i}$

### Reglas de Fragmentación para Fragmentación Vertical
#Q 
- En todos los fragmentos deben estar :: El o los atributos que conforman la PK.
1. Regla de Completitud :: Cada atributo de R está contenido en uno de los fragmentos.
2. Regla de Disyunción :: $R_{i} := \pi_{K, A_{i1},\dots,A_{im}}(R)$
3. Regla de Reconstrucción :: $R = R_{1} \Join R_{2} \Join \cdots \Join R_{n}$
