## How Parsing Is Divided?
Parsing has two phases:
1. **Lexical Analysis:** Split the code in *tokens*, which are the pieces that make up the syntax.
2. **Syntactic Analysis:** Use and format the tokens to create a representation that describes each part of the syntax and their relations. Typically done with an **Abstract Syntax Tree (AST)**.

## Example
Considering the following code, build a token array and an AST:
```lisp
(add 2 (subtract 4 2))
```
