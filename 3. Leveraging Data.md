## Data Sources
Se dividen en 3 categorías: Spreadsheets, databases y otros (drive, calendar, salesforce, etc.)
Añadir nuevo datasource: My Account > New Datasource > Choose Datasource
Configurar app para usar datasource: Data > New Table

## Define Data Structure
AppSheet lo hace automático, pero se puede checar y hacer manual en Data > Table.
Key es la: Identificador único, es constante
Label: Mostar o no el nombre de la columna.
Virtual Columns: Son las columnas con un _ al inicio.
Las imágenes son almacenadas como un URL o como un PATH.
