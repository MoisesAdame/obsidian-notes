## 语法
### 1. ”正好“的用途
#### 特点
正好的用途是两个：
1. 可以做**形容词**，代表适合的时间、程度、数量等等。
2. 可以做**副词**，代表遇到某个机会做某事。

#### 例子
1. 你和你妻子的关系**正好**，你们俩从来不互相麻烦。
2. 我父母**正好**的买了我们的家，现在越来越贵！

### 2. "差不多"和"几乎"的不同点

| 用法点                                       | 例子                  |
| ----------------------------------------- | ------------------- |
| 1. **差不多**可以用在单音节形容词的前面。**几乎**应该有后面和前面的词。 | 我们*差不多*高。他们*几乎*一样高， |
| 2. **差不多**可以用在数量词的前面。                     | 你**差不多**一米七高。       |
| 3. **差不多**可以是形容词，做谓语。                     | 姐妹俩性格**差不多**。       |
| 4. 几乎可以代表说话的人不希望发生的事                      | 我**几乎**忘了我钱包。       |

### 3. "尽管"的用途
#### 特点
在第一句分提出一个**事实**，后一分句是一个**不会的结果**。

#### 语法
尽管。。。，但是/还是/可是/却。。。

#### 例如
- **尽管**他不会说英语，**但是**成功地去美国旅游。
