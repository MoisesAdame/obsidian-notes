## 重要的概念和性质
#Q 
集合的对象称为 :: 元素
如果A和B是两个集合，且对于任意的元素t都有$t \in A$当且仅当$t \in B$，那么 :: $A = B$
如果A集合所有的元素也是B集合的元素，那A是什么？:: A集合是B集合的子集。
一个集合的幂集是那个集合的 :: 所有子集
A幂集（$\mathbb{P}$）的元素是A集合的 :: 所有子集。
