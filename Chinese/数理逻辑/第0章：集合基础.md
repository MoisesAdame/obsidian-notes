## 重要的概念和性质
#Q 
集合的对象称为 :: **元素**
如果A和B是两个集合，且对于任意的元素t都有$t \in A$当且仅当$t \in B$，那么 :: $A = B$
如果A集合所有的元素也是B集合的元素，那A是什么？:: A集合是B集合的**子集**。
**A幂集**（$P(A)$）的元素是A集合的 :: 所有的子集。
A与B的**并集**是什么 :: 属于A或属于B的元素的集合。
A与B的**交集**是什么 :: 是所有A与B共有的元素的集合。
如果A与B的交集是空集，那么A与B是什么样的集合 :: **不相交**的集合。
一个**关系**是个 :: 有序对的集合。
R的**定义域**是什么？:: 是所有满足$(x,y) \in R$的元素$x$的集合。
R的**值域**是什么？:: 是所有满足$(x,y) \in R$的元素$y$的集合。
