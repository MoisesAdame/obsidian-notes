## Early days

- Initially one had to feed the computer with cards.
- A card deck for the **compiler** a card deck for the **source code**, a card deck for the **loader**, etc.

### Batch Operating Systems

- Made to **optimize** idle time between card deck handling.
- **Main Storage:** Store the source code.
- **Secondary Storage:** Store compiler, loader, etc.
- Unfortunately all the main storage was used only by one program. So we created **multiprogramming operating systems**

### Multiprogramming Operating Systems

- Run more than 1 program in the core.
- Multiprogramming OS came in two flavors:
	- Multiprogramming with **Fixed** Tasks (MFT): **Fixed** portion of core.
	- Multiprogramming with **Variable** Tasks (MVT): **Varying** portion of core.
- This led to **fragmentation**, which is the problem of having spaces between source code in the core.
- To avoid fragmentations 2 **memory allocation methods** where invented:
	- Relocatable Partitions.
	- Paging.

#### Memory Allocation Methods
##### Paging
- Both core and the program are divided in equal **pages**.
- There are two types of paging: **Simple** and **On-Demand**.
	- Simple Paging: All the pages must be in core.
	- On-Demand Paging: Pages are fetched as they are needed.

##### Relocatable Partitions
- Unused parts are condensed in one part.

## Multiprocessing Operating System
- A system with multiple processors.
- Everything (processors and processes) are controlled by the **traffic controller**.
- The processor time is allocated by the **scheduler**.
- The files are allocated by the **file system**.
	- A file is a segment.
	- There are two types of files: Directories and programs or data.
