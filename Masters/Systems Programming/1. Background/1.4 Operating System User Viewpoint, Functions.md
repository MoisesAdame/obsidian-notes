## Common View of the Operating System

For us, users, the OS does the following things:
- Manage **time and processes**: Scheduling, traffic controller.
- **I/O** Programming.
- **Protection** from user.
- Management of the **secondary storage**.
- Handle **errors**.

### Input/Output
- Should be thought as another computer.
- Can be done while executing a program.
