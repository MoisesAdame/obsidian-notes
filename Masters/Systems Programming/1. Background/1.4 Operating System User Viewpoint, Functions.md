## Common View of the Operating System

For us, users, the OS does the following things:
- Manage **time and processes**: Scheduling, traffic controller.
- **I/O** Programming.
- **Protection** from user.
- Management of the **secondary storage**.
- Handle **errors**.

### Input/Output
- Should be thought as another computer.
- Can be done while executing a program.

### Protection
- The OS must ensure **inviolability**.
- Avoid the system from crashing.

### Secondary Storage
- Task performed with the use of disks, tapes and nowadays hardrives.
- Used to store the user's **programs** and **data**.

### Error Handling
- It is not efficient to wait for the user to **handle errors**.
- The os should do the appropriate action.
