## Components of a Programming System
- They are 5:
	1. Assembler
	2. Macro Processor
	3. Loader
	4. Compiler
	5. Operating System

### 1. Assembler
- **Input:** Assembly Language.
- **Output:** Object program

### 2. Macro Processor
- **Maco Call:** The name for a piece of code.
- **Macro Definition:** The piece of code.
- **Macro Processor:** The program who *substitutes* macro calls, for macro definitions.

### 3. Loader
- Routine that *loads* the object program.
- Prepares it for *execution*.
- The general steps are: Load, Relocate and Link.

### 4. Compiler
- Translator from **human code** (high level) to **object program**.

### 5. Operating System
- The one responsible for allocating: Resources and Services.
- Has programs like: Scheduler, traffic controller, memory manager, etc.
