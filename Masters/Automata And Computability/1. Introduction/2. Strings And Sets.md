## Definitions

- **Alphabet ( $\sum$ ):** Is a *finite* set of letters or symbols.
- **String Over $\sum$**: A finite length sequence of elements of $\sum$.
- **Set of All Strings over $\sum$ ( $\sum^*$ )**: Is a *finite* set that contains all the strings that can be constructed using the alphabet $\sum$.
- **Length:** The number of characters in a string. $|x|=n$.
- **Null String ( $\epsilon$ ):** A string $x$ that satisfies that $|x|=0$

## Operations on Strings

### Concatenation

- **Definition:** If $x$ and $y$ are strings, then $xy$ is the concatenation of them.
- Properties:
	- **Associativity:** $(xy)z=x(yz)$
	- **Identity:** $\epsilon x = x$
	- **Length:** $|xy|=|x|+|y|$
- Notation:
	- $x^n=x x x x \cdots x$ ($n$ times).
	- If $a\in \sum$ and $b \in \sum^*$, then $\#a(b)$ is the number of $a$ in $b$.
	- **Prefix:** Is any string $y$, such that $x=yz$.
		- $\epsilon$ is the prefix of every string.
		- Every string is the prefix of itself.
		- **Proper Prefix:** Is a prefix $y$ of $x$ such that $y \neq \epsilon$ and $y \neq x$.
