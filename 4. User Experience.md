## Introduction to AppSheet Views
La view tiene varias cosas: Nombre, tabla, tipo (calendario, histograma, etc), opciones.

## Using Views in AppSheet
View tiene View Name
For this data: Tiene la tabla
Position: Desde donde se accede a la view.
Display: Son cosas como el nombre, icono, show if
Primary Views: Son las que se pueden acceder desde la parte baja.
System Views: Automatically generated views
Ref View: Views que salen al indagar en los datos.

## Customizing the UX of your app
En Settings > Theme & Brand, se puede alterar todo lo relacionado con el UX de la aplicación.
Una Format Rule: Formatos condicionales
About Page: Info > Properties. Establecer todos los datos del App.
