## 时间序列分析的目标
#Q 
- 截至（jié zhì，up to）时刻t可以获得的历史信息是 :: $y_{t - L + 1 : t}, x_{t - L + 1}^{past}$
- 未来已知消息是 :: $x_{t - L + 1: t + H}^{known}$
- 静态（static）信息 :: $c$
- 定义$F_{t} = \{ y_{t - L + 1 : t}, x_{t - L + 1}^{past}, x_{t - L + 1: t + H}^{known}, c \}$是时刻t所有可以获得的消息，时序（sequential timing）预测目标为构建（construct） :: $p(Y_{t - L + 1: t + H}|F_{t})$

## 时间序列分析和回归（regression）
#Q 
- 监督学习常嘉定样本（sample）是 :: 独立/可交换（exchangeable）的。
- 时序显式（explicitly）利用 :: 依赖（dependence）
- 监督学习和时间序列分析在某些方面有相似处，比如说间序列分析也可以使用... 进行... :: 最小二乘方法（least squares method），参数（parameter）估计。

## 时间让普通学习问题发生变化
#Q 
- 时序预测有3个重点的特点 :: Temporal Dependency, Time Direction & Distribution Change
- Temporal Dependency的意思就是过去可能包含关于...信息 :: 未来
- Time Direction的意思是未来数据不能反过来帮助 :: 过去的预测。
- Distribution Change就是序列的...、...、...可能随时间变化 :: 水平，趋势（qū shì；trend），波动规律（bō dòng guī lǜ；fluctuation laws）

- 假设样本有两个特点 :: 独立和同分布（i.i.d）。

### 时间序列
#Q 
- 样本之间存在什么样的关系？ :: 依赖关系。
- 后续样本依赖什么？ :: 以往（past）样本。
- 基于（jī yú；on account of）不同的上下文属性有不同的什么？ :: 概率假设
- 如果我们忽略（hū lüè；ignore）依赖关系的话，就转化为……问题（假设信息是……） :: 回归，独立和同分布的。

## 时间序列的三种观察（guān chá；observe）方式
#Q 
- 目前时间序列的三种观察是：a) 统计（tǒng jì；statistical）建模（model building）：时域视角。b）统计建模：频域视角。c）数据驱动（qū dòng；driven）：机器学习视角。
- 统计建模：时域视角重视两个方面 :: 依赖结构与随机过程。
- 统计建模：频域视角重视 :: 不同的频率（pín lǜ；frequency）成分。
- 数据驱动：机器学习视角能够从数据学习什么？ :: 预测映射。
- 目前模型用什么视角？ :: 目前模型往往融合三种观察。
