## 时间序列分析的目标
#Q 
- 截至（jié zhì，up to）时刻t可以获得的历史信息是 :: $y_{t - L + 1 : t}, x_{t - L + 1}^{past}$
- 未来已知消息是 :: $x_{t - L + 1: t + H}^{known}$
- 静态（static）信息 :: $c$
- 定义$F_{t} = \{ y_{t - L + 1 : t}, x_{t - L + 1}^{past}, x_{t - L + 1: t + H}^{known}, c \}$是时刻t所有可以获得的消息，时序（sequential timing）预测目标为构建（construct） :: $p(Y_{t - L + 1: t + H}|F_{t})$

## 时间让普通学习问题发生变化
#Q 
- 时序预测有3个重点的特点 :: Temporal Dependency, Time Direction & Distribution Change
- Temporal Dependency的意思就是过去可能包含关于...信息 :: 未来
- Time Direction的意思是未来数据不能反过来帮助 :: 过去的预测。
- Distribution Change就是序列的...、...、...可能随时间变化 :: 水平，趋势（qū shì；trend），波动规律（bō dòng guī lǜ；fluctuation laws）

#Q

## 小麦价格序列例子
#Q 
- 给定$Y_{t}$，如何预测下一个月的价格？
	- 假定价格**不变化**那 :: $\hat{y}_{t+1|t} = y_{t}$ 
	- 那真实价格（$y_{t+q}$）和预测价格（$\hat{y}_{t+1|t}$）残差（cán chā；residual）为 :: $\epsilon_{t+1} = y_{t+1} - \hat{y}_{t+1|t}$。
	- 因为$\epsilon_{t+1} = y_{t+q} - \hat{y}_{t+1|t}$，所以$Y_{t}$和$Y_{t-1}$有什么关系？:: $Y_{t} = Y_{t+1} + \epsilon_{t}$
- 这个问题有两个分析方法 :: 不稳定方法和稳定方法。
- **不稳定**的方法是用$Y_{t} = Y_{t+1} + \epsilon_{t}$，问题是$\epsilon_{t}$是个互不相关的随机变量，也可以叫做 :: 白噪声（bái zào shēng；white noise）
- 如果展开$Y_{t} = Y_{t+1} + \epsilon_{t}$的话，$Y_{t} =$啥？这个模型就是啥？::  $Y_{t} =\epsilon_{t} + \epsilon_{t-1} + \epsilon_{t-2} + \cdots$, 随机游走（random walk）
- **稳定**的方法是加上个系数（coefficient）$\phi$ s.t. $|\phi|<1$，所以模型会长得咋样？该模型为什么？:: $Y_{t} = \phi Y_{t+1} + \epsilon_{t}$，AR（1）模型。
- 这个例子表示AR(1)模型可以变成随机游走要是啥？:: $\phi = 1$.

## 一个时间序列的例子：季节因素
#Q 
- 用小麦价格的例子，**环比（period on period）**：基于$Y_{t-1}$进行预测（公式） :: $Y_{t} = \phi Y_{t-1} + \epsilon_{t}$
-  用小麦价格的例子，**同比（same period of last year）**：基于$Y_{t-12}$进行预测（公式） :: $Y_{t} = \psi Y_{t-12} + \epsilon_{t}$
- 混合环比和同比在一起进行预测（公式）:: $Y_{t} = \phi Y_{t-1} + \psi (Y_{t-12} - Y_{t-13})\epsilon_{t}$
