## 时间序列的统计量
### 分析“平稳”的时间序列
#### 严平稳（Strongly Stationary）
#Q 
- 为了认为**平稳**，所有的统计性质都*不会*随着时间的推移而发生..... :: 变化。
- 公式 :: $\forall n, \forall(t_{1}, t_{2},\dots, t_n)$ 有 $(Y_1,\dots,Y_{t_{n}})\triangleq(Y_{t_{1}+h},\dots,Y_{t_{n}+h}),\forall n,t_{1},\dots,t_{n},h$

### 如何描述一个随机过程
#### 传统的统计量
#Q 
- 均值 :: $\mu=\mathbb{E}[Y]\int_{-\infty}^\infty yf(y)dy$
- 协方差 :: $Cov[X, Y]=\mathbb{E}[(Y-\mu_{Y})(X-\mu_{X})]$
- 方差 :: $Var[Y]=\mathbb{E}[(Y-\mu_{Y})^2]$

#### 时间序列的统计量
#Q 
- 均值 :: $\mu(t)=\mathbb{E}[Y(t)]=\int_{\infty}^\infty yf_{Y(t)}(y)dy$
- 自协方差 :: $\gamma_{YY}(t_{1}, t_{2})=\gamma(t_{1}, t_{2})=Cov[Y(t_{1}), Y(t_{2})]=\mathbb{E}[(Y(t_{1}) - \mu(t_{1}))(Y(t_{2}) - \mu(t_{2}))]$
- 为啥时间序列有自协方差？:: 因为他们多考虑时间依赖。
- 方差 :: $\sigma^2(t)=\gamma_{YY}(t, t)=V[Y(t)]=\mathbb{E}[(Y(t)-\mu(t)^2]$

### 自协方差系数以及自相关系数
#### 严平稳下，自协方差（$\gamma_{YY}(k)$）
#Q 
- 在严平稳条件下，因此自协方差仅仅依赖于…… :: 间隔的长度（$k$）。
- 间隔长度（$k$）的自协方差公式是…… :: $\gamma_{YY}(k)=Cov[Y_{t}, Y_{t+k}]=\mathbb{E}[(Y_{t} - \mu_{Y})(Y_{t+k} - \mu_{Y})]$

#### 自相关系数（$\rho_{YY}(k)$）
#Q 
- 把自协方差标准化到…… :: $[-1, 1]$之间。
- 公式 :: $\rho_{YY}(k)=\frac{\gamma_{YY}(k)}{\gamma_{YY}(0)}=\frac{\gamma_{YY}(k)}{\sigma^2_{Y}}$

### 弱化“平稳”性条件（weakly stationary process）
#Q 
- 因为严平稳的要求太难了，因此需要……不同时刻随机变量关系的约束 :: 放松。
- **k阶宽平稳（weakly stationary of order k）**：随机过程的……不随时变化 :: 前k阶矩。
- 例如：2阶宽平稳。均值……，方差……，自协方差…… :: $\mu(t)=\mu$, $\sigma^2(t)=\sigma$, $\gamma(t_{1}, t_{2})=\gamma(t_{1}-t_{2})$
- 推到2阶宽平稳的自协方差 :: $\gamma_{TT}(t_{1}, t_{2})=Cov[Y(t_{1}),Y(t_{2})],\text{因为二阶宽平稳}\implies Cov[Y(t_{1}),Y(t_{2})]=Cov[Y(t_{1} +h),Y(t_{2}+h)]$ thus if we let $h=-t_{2}$ we get $\gamma_{TT}(t_{1}, t_{2})=Cov[Y(t_{1} - t_{2}),Y(0)]$

## 时间序列分析化简
### Wold 分解：确定性部分与非确定性部分
#Q 
- **Wold分解定理**：任意离散时间平稳过程$\{ X_{t} \}$可以写成…… :: $X_{t}=S_{t}=D_{t}$其中： $S_{t}$是个随机过程，$D_{t}$是个确定性过程。
- **核心思想**：未来……（什么样的）结构 + 真正新的…… :: 可预测的，随机冲击
- **老师写的Wold分解定理**: 设 $\{ X_{t} \}$ 为零均值协方差平稳过程，则存在唯一的分解…… :: $X_{t} - \mu = V_{t} + \sum_{j=0}^\infty \psi_{j}\varepsilon_{t-j},t\in \mathbb{Z}$。其中：$V_{t}$是确定性部分，$\{ \varepsilon_{t} \}$是创新序列（白噪声）。

### Wold 分解的 MA(∞) 形式
#Q 
- 若一个**平稳过程**的最佳线性预测误差的方差在所有期都严格大于 0，则称该过程为…… :: 纯非确定性。
- 对于**纯非确定性平稳过程**$\{ X_{t} \}$，可以表示为创新项的无限阶……，公式…… :: $X_{t}=\sum_{j=0}^\infty \psi_{j}\varepsilon_{t-j}, \psi_{1}=1$

### Cramér表示：频域叠加视角
#Q 
- **平稳过程**可以表示为……的连续叠加 :: 不同频率的正弦波。
- Cramer表示的公式…… :: $X_{t}=\int_{-\pi}^{\pi}e^{ i\omega t }dZ(\omega)$。其中：$e^{ i\omega t }$因为欧拉公式它有正弦和余弦，$Z(\omega)$代表各频率分量的随机幅度和相 位，$\omega$代表频率。
