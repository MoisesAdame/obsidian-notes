## 0. 线性过程
### 延迟算子B
#Q 
- $BY_{t}=$ :: $Y_{t-1}$
- $B^{-1}Y_{t}=$ :: $Y_{t+1}$
-  $B(aY_{t}+bX_{t})=$ :: $aY_{t-1} + bX_{t-1}$

### 线性过程
#Q 
- 一个输入是白噪声的系统的输出是…… :: 线性过程。
- 公式…… :: $Y_{t} - \mu = \sum_{i=0}^\infty \psi_{i}\varepsilon_{t-i}，\psi_{0}=1$。其中：$\mu$是过程的均值，$\{ \varepsilon_{t} \}$是白噪声，$\{ \psi_{i} \}$影响权力。
- 用**延迟算子B**，我们可以把原来的公式写成…… :: $Y_{t}=\varepsilon_{t} + \psi_{1}\varepsilon_{t-1}+\psi_{2}\varepsilon_{t-2}+\cdots=\varepsilon_{t}(1+\psi_{1}B+\psi_{2}B^2+\cdots)=\psi(B)\varepsilon_{t}$。这里$\mu=0$而$\psi(B)=1+\sum_{i=1}^\infty B^i$

### $\psi$加权与$\pi$加权
#Q 
- $\psi$加权公式…… :: $\psi(B)=1+\sum_{i=1}^\infty B^i$
- $\pi$加权公式…… :: $\pi(B)=1+\sum_{i=1}^\infty \pi_{i}B^i$
- 用$\pi(B)$我们可以获得**第t时刻的白噪声项**…… :: $\pi(B)Y_{t}=\varepsilon_{t}$
- $\psi$加权和$\pi$加权的关系公式…… :: $\psi(B)\pi(B)=1$

### 线性过程的统计性质
#Q 
- 均值…… :: $\mathbb{E}[Y_{t}]=\mu$（证明：[[NJU/时间系列/证明/第5课|第5课]]第1点）
- 自协方差…… :: $\gamma(k)=Cov\left[ \sum_{i=0}^\infty \psi_{i}\epsilon_{t-i},\sum_{i=0}^\infty \psi_{i}\epsilon_{t+k-i}\right]=\sigma_{\epsilon}^2\sum_{i=0}^\infty\psi_{i}\psi_{k}$
- 方差…… :: $\gamma(0)=Var(Y_{t})=\sigma_{\epsilon}^2\sum_{j=0}^\infty \psi_{j}^2$

## 1. AR模型
### AR模型的定义
#Q 
- AR(p)公式……，$\epsilon_{t}$的分布…… :: $Y_{t}=c + \sum_{i=1}^p\phi_{i}Y_{t-i}+\epsilon_{t}$, $WN(0, \sigma^2)$
- 特征多项式（lag polynomial）…… :: $\Phi(B)=1 - \phi_{1} B - \cdots-\phi_{p}B^p$ 
- AR模型总是**平稳**的？ :: 不是
- AR模型平稳的**条件** :: $\Phi(z)=0$
- **均值**（若平稳）:: $\mu=\frac{c}{1-\phi_{1}-\cdots-\phi_{p}}$

### AR模型平稳性判别
#Q 
- 为了AR模型是个平稳的过程，它特征根（$\Phi(z)=0$）应该在 :: 单位圆的外面。
- 为了AR模型是个平稳的过程，它特征根（$\Phi(z)=0$）应该在 :: 平稳域里面（三角形）
