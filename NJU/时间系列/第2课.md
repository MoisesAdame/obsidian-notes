## GIFT-EVAL：从模型比较到通用预测能力评估（evaluate）

- GIFT-EVAL按四个task characteristics分析 :: Domain, Frequency, Prediction Length, # Variates
- GIFT-EVAL更合适大模型时代因为比如说LTSF只适合比较…… :: 特定架构的模型。

## 漂移预测（Drift Method）
#Q 
- Drift方法：充分考虑到时间序列…… :: 前后（front and back）的变化。
- 每两个相邻的时间序列可以计算 :: 变化值的均值。
- 数学表达式 :: $\hat{y}_{n+h} = y_{n} + \frac{h}{n-1}\sum_{t = 2}^{n} (y_{t} - y_{t-1}) = y_{n} + h\left( \frac{y_{n} - y_{1}}{n-1} \right)$

## 时间序列的距离
#Q 
- 在时间系列分析中计算“距离”就是问 :: 这些曲线长得像不像？
- 不同距离从不同的角度定义…… :: 相似性
- 可以计算什么区域的距离？:: 时域和变换域
- 有的计算机“距离”方法是 :: Lock-Step, Elastic, Edit Based, Feature Embedding & Distribution/Kernel
- **Lock Step**是个逐点比较，数学公式是…… :: $\left(\sum_{t = 1}^n |x_{t} - y_{t}|^p\right)^{1/p}$
- **Elastic**允许局部（some parts）时间……，合适相位（phase）…… :: 变形，偏移。
- **Edit Based**把一条曲线通过删、改、增变成 :: 另外一条曲线。
- **Feature-Embedding**先提取……，把它们压成一个……（这个叫做……）再对比…… :: 特征，向量，embedding，距离
- **Distribution Kernel**比较短片的……或者……，合适那种模型……比较？:: 分布，相似性，统计。

## Dynamic Time Warping
#Q 
- DTW用于计算不同……时间序列的距离，这些时间序列的形状……，但是峰谷（fēng gǔ；picos y valles）出现时间…… :: 长度，相似，不一样。
- DTW允许局部发生啥……（2个事情）后，再计算整体相似性 :: 拉伸，压缩。
- DTW的数学公式是 :: $DTW(i, j) = distance(x_{i}, y_{j}) + min\{ DTW(i, j-1), DTW(i-1, j), DTW(i-1, j-1) \}$

## 其他距离形式
#Q

- 也有别的距离形式例如 :: Edit Distance on Real Sequences, Minimum Jump Costs Dissimilarity.

## 预测评价指标（index）
#Q 
- 设$y_{i}$是真实值，$\hat{y}_{i}$是预测值，$e_{t}$等于 :: $e_{t} = |y_{t} - \hat{y}_{t}|$
- MAE（Mean Absolute Error）汉语中叫……，数学公式…… :: 平均绝对误差，$\frac{1}{n} \sum_{t = 1}^n e_{t}$
