## 概率预测指标
### 分位数预测：Pinball / Quantile Score
#Q  #AOSR/1jr5c
- **定义**：在时刻𝑡，预测未来𝑡 + ℎ时刻：对于一个给定的分位水平（quartile score）$\tau \in (0,1)$，模型输出$\hat{y}_{t+h | t}^{(\tau)}$，表示模型认为未来随机变量……有大约$\tau$的概率不超过这个值，既…… :: $Y_{t+h}$，$P(Y_{t+h} \geq \hat{y}_{t+h | t}^{(\tau)}) \approx \tau$ #AOSR/1jr5c/s/1k99
- **如何评价某个分位数预测是否准确？** 定义$\hat{q}_{\tau}$是……，评测关键点：对过高/过低预测的惩罚不……（啥样）；$\tau$越大越关注…… :: $\hat{y}_{t+h | t}^{(\tau)}$，对称，上尾风险（upper tail risk） #AOSR/1jr5c/s/7ij3
- $QS_{\tau}(y,\hat{q}_{\tau})$（其中：$y$是真实观测值，$\hat{q}_{\tau}$是预测分位数）的数学公式是 :: $\begin{cases} \tau(y -\hat{q}_{\tau}) & y \geq \hat{q}_{\tau} \\ (1 - \tau)(\hat{q}_{\tau} - y) & y < \hat{q}_{\tau} \end{cases}$ #AOSR/1jr5c/s/6rmn

### 区间预测：Coverage/Interval Score
#Q #AOSR/20a7a
- **定义**：对于未来$t + h$，模型给出一个置信水平为$1-\alpha$的预测区间$[\hat{l}_{t+h|t}, \hat{u}_{t+h|t}]$如果是中心100(1− 𝛼)%区间：$\hat{l}_{t+h|t}$是……，$\hat{u}_{t+h|t}$是…… :: $\hat{y}_{t+h|t}^{(\frac{\alpha}{2})}$，$\hat{y}_{t+h|t}^{(\frac{1-\alpha}{2})}$ #AOSR/20a7a/s/440a

#### Coverage
#Q  #AOSR/6vg0m
- **目的**：评价预测区间是否……（做啥）真实值 :: 覆盖 #AOSR/6vg0m/s/1vk7
- **关键点**：只反映“是否*覆盖*”，不能单独衡量区间是否过…… :: 宽。 #AOSR/6vg0m/s/sfei
- **Coverage的数学公式（$I_{t,h}^{(\alpha)}$）**：:: $I_{t,h}^{(\alpha)} = \mathbb{1}\{ \hat{l}_{t+h|t} < y_{t+h} < \hat{u}_{t+h|t} \}$ #AOSR/6vg0m/s/5j81
- **例如**：Coverage = 0.99：不一定更好，可能只是区间太…… :: 宽。 #AOSR/6vg0m/s/6ghi
- Coverage 评价……：模型声称（claim）“90%会覆盖”，长期来看是否真的约有90%被覆盖。:: Calibration #AOSR/6vg0m/s/7leg

#### Interval Score
#Q  #AOSR/49u87
- **目的**：同时考虑区间宽度与是否…… :: 漏包（smaller of 漏掉包住） #AOSR/49u87/s/psfq
- **Interval Score的数学公式（$IS_{\alpha}(y, \hat{l}, \hat{u}$）**：:: $IS_{\alpha}(y, \hat{l}, \hat{u}) = \hat{u} - \hat{l} + \frac{2}{\alpha} (\hat{l} - y)\mathbb{1}\{ y < \hat{l} \} +\frac{2}{\alpha}(y - \hat{u})\mathbb{1}\{ y > \hat{u} \}$ #AOSR/49u87/s/48qo
- 在$IS_{\alpha}(y, \hat{l}, \hat{u})$中$\hat{u} - \hat{l}$项表示 :: 区间宽度。 #AOSR/49u87/s/vjck
- 在$IS_{\alpha}(y, \hat{l}, \hat{u})$中$\frac{2}{\alpha} (\hat{l} - y)\mathbb{1}\{ y < \hat{l} \}$项表示 :: 下界漏包惩罚（chéng fá；penalty）。 #AOSR/49u87/s/6diq
- 在$IS_{\alpha}(y, \hat{l}, \hat{u})$中$\frac{2}{\alpha}(y - \hat{u})\mathbb{1}\{ y > \hat{u} \}$项表示 :: 上界漏包惩罚。 #AOSR/49u87/s/20tl

### 分布预测：CRPS
#Q  #AOSR/5e58i
- **定义**：我们本来有两个东西：1）模型给出的未来**随机变量$Y_{t+h}$**。2）老天给我们的**真实观测值$y$**。要是把它们俩变成累积分布函数（CDF）我们收到……，然后计算这两条线之间的面积差……，这个面积差叫做…… :: $\hat{F}_{t,h}(z) = P(Y_{t+h} \leq z | \mathbb{F}_{t})$与$\mathbb{1}\{ z \geq y \}$，$CRPS(\hat{F}, y) = \int_{-\infty}^{\infty} (\hat{F}_{t, h}(z) - \mathbb{1}\{ z \geq y \})^2$，Continuous Ranked Probability Score #AOSR/5e58i/s/2pk7
- CRPS同时体现（to embody）两个东西……和……，数字越小越…… :: 校准（calibration），集中度（sharpness），好。 #AOSR/5e58i/s/5sga
- 既$\hat{p}(x)$预测分布，用$y$可以计算NLL（Negative Log Likelihood）汉语中叫……，数学公式是……，因为$\hat{p}(x)$是个钟形的曲线，$\hat{p}(y)$越高，NLL越……，这个是…… :: 负对数似然，$NLL = -\log(\hat{p}(y))$，小，好事。 #AOSR/5e58i/s/5smj

#### 如何处理负值序列
#Q  #AOSR/7kafu
- **二参数Box-Cox变换**：数学公式……，允许…… :: $y_{t}^{(\lambda)} = \begin{cases} \frac{(y_{t} + \lambda_{2})^{\lambda_{1}} - 1}{\lambda_{1}} & \lambda_{1} \neq 0 \\ \ln(y_{t} + \lambda_{2}) & \lambda_{1} = 0\end{cases}$，$y_{t} > -\lambda_{2}$ #AOSR/7kafu/s/fpp6
- **修正Box-Cox变换（Bickel & Doksum）**：数学公式…… :: $y_{t}^{(\lambda)} = \begin{cases} \log(y_{t}) & \lambda = 0 \\ \frac{sign(y_{t})|y_{t}|^{\lambda} - 1}{\lambda} & \lambda \neq 0\end{cases}$ #AOSR/7kafu/s/25pd
- **Yeo-Johnson变换**：数学公式…… :: $y_{t}^{(\lambda)} = \begin{cases}\frac{(y_{t} + 1)^\lambda - 1}{\lambda} & \lambda \neq 0, y \geq 0 \\ \log(y_{t} + 1) & \lambda = 0, y \geq 0 \\ -\frac{(-y_{t} + 1)^{2-\lambda} - 1}{2-\lambda} & \lambda \neq 2, y<0 \\ -\log(-y_{t} + 1) & \lambda = 2, y<0\end{cases}$
