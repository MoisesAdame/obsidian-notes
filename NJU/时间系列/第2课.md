4. **Maurice Presley**说时间序列分析本身是为了找到最能够反应时序数据特性的……而预测任务的目标为找到……。如果时间序列满足Box-Jenkins模型（ARIMA）的假设，则使用ARMIA就是…… :: 单一模型，这个模型，最优的选择。

## LTSF Benchmark：统一（unified）设置（set up）下比较预测模型
#Q 
- LTSF Benchmark的意思是 :: Long Term Time Series Forecasting Benchmark
- 这个Benchmark考什么条件？:: 固定的数据集、固定的数据划分（division）、固定的输入和预测长度

### LTSF Benchmark的优点
#Q 
- 最基本的就是可以…… :: Standardization（标准化）
- 模型容易复现，这个就是 :: Reproducibility
- Architecture-oriented，比如说可以对比Tranformer A和Transformer B再知道 :: 谁在long-term forecasting好一点。

### LTSF Benchmark的确定（问题）
#Q 
- 领域和数据规模（scale）有…… :: 限。
- task setting太…… :: 固定
- 主要评价什么预测？ :: point forecast

## GIFT-EVAL：从模型比较到通用预测能力评估（evaluate）
#Q 
- 老的评估方法就是问“你的模型在某个数据集上的……多少”。:: MSE (Mean Squared Error)
- GIFT-EVAL想知道你的模型善于……时间序列。:: 什么类型的
- GIFT-EVAL按四个task characteristics分析 :: Domain, Frequency, Prediction Length, # Variates
- GIFT-EVAL更合适大模型时代因为比如说LTSF只适合比较…… :: 特定架构的模型。

## 从广覆盖到真实 Forecasting Tasks
#Q 
- 这里学的benchmark叫做 :: fev-bench
- fev-bench进一步（further）强调真实……和统计置信区间 :: covariates(协变量)
- benchmark中的基本单位定义成 :: Forecasting Task
- 一个task包括 :: dataset、target、covariates、horizon 𝐻、evaluation cutoff 、metric。
- 同一个dataset可以因为target、covariates、horizon等不同而形成不同的 :: forecasting tasks
- fev-bench不再倾向于（qīng xiàng yú；incline towards）96/192/336/720（LTSF的step 数）而是选择更贴近任务的…… :: Horizon
