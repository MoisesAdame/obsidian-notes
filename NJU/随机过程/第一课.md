## Definición
$$
{X(t) : t \in T}
$$
where X(t) is a random variable
t is time.

Can have discrete time and continous

Random Variable: X: S -> R. A function that assigns a real value to each outcome

## Example
### Particle moving clock wise or anti-clockwise

X_n: Position after n steps.

Target Event: E_i is the last visited node until visiting all nodes.

$$
P(E_{i}) = P(E_{i} : T_{i - 1} < T_{i + 1}) / P(E_{i} | T_{i-1} > T_{i+1})
$$

### Rays Moving within neighbors
$P(E_{i}) = \sum_{k} P(E_{i} | C_{k}) P(C_{k})$

$$
P(E_{i} | C_{i}) = P(W_{ni}) + (1-P(W_{ni})) P(E_{i})
$$

We can say that for $k \neq i$
$$
P(E_{i} | C_{k}) = P(W_{nk}) * 0 + (1-P(W_{ni}))
$$

$$
P(E_{i}) = \frac{\frac{1}{n_{i}}}{\sum_{k = 1}^r \frac{1}{n_{k}}}
$$

## Preliminaries
### Independence of Random Variables
Independent if $P(X = x,  Y = y) = P(X = x) P(Y = y)$

### Expected Value
$$
E[X] = \sum_{x} xP(X = x)
$$
Two common ways:
1. If X1, X2, ..., Xn, then E[X] = sum_i = 1 E[X_i]
2. E[X] = E(E(E|Y))

Proof of 1
$$
E[X + Y] = \sum_{x}\sum_{y}(x+y)P(X = x, Y = y)
$$
