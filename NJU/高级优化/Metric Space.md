## Definition 
A metric space is a set $X$ that has a metric function $d : X^2 \to \mathbb{R}$ satisfying the following properties for all $x, y, z \in X$:
1. **Non-Negativity**: $d(x, y) \geq 0$ and $d(x, y) = 0 \iff x=y$
2. **Simmetry**: $d(x, y) = d(y, x)$
3. **Triangle Inequality**: $d(x, z) \leq d(x, y) + d(y, z)$
