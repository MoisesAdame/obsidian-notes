## Building Blocks
- **Constants**: Names for specific objects (a, b)
- **Variables**: Placeholders for the names.
- **Predicates**: Properties of or relations between objects (Loves (x, y))
- **Functions**: Map from one object to another (a = Father(b))
- **Terms**: Constants, variables or functions applied to terms (best_friend(moy))

## Complex Concepts
### Standard Names
The **keys** of our database.

If all the *terms* are divided into *equivalence classes* (A set were all the objects are rsflexive, symetric and transit), then each equivalence class is one **standard name**.
