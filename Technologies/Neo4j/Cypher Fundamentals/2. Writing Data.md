## Create a Node

- It is done using the **MERGE** sentence and specifying the type and the properties.

```cypher
MERGE (p:Person {name: 'Michael Caine'})
```

- Another option is using **CREATE**, but it has the problem that it **doesn't check for repeated nodes**.
- The advantage it is faster.

```cypher
CREATE (p:Person {name: 'Michael Caine'})
```

## Creating Relationships

- It can be done using the **MERGE** sentence.
- We have to specify *direction* and *type* of the relation.

```cypher
MATCH (p: Person {name: 'Michael Caine'})
MATCH (m: Movie {title: 'The Dark Knight'})
MERGE (p)-[:ACTED_IN]->(m)
```

- We can create nodes and relationships at the same time.
- If the direction is not specified, it is take as<span style="color:#00b0f0"> left to right --></span>.

```cypher
MERGE (p: Person {name: 'Michael Cera'})
MERGE (m: Movie {title: 'Super Bad'})
MERGE (p) - [:ACTED_IN] - (m)
```
