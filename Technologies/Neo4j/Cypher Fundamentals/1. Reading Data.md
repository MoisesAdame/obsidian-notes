## Simple Queries

- Nodes in node4j are represented as *parenthesis ()*.
- A simple query would look like this.

```cypher
MATCH (m: Movie) 
WHERE m {title: 'The Matrix'}
RETURN m.tagline
```

## Patterns

- A patter in cypher can look like this: **() --> ()**. This will give us all the nodes (of any type) that are related to any other node (of any type).
- To filter depending on the relation we use **() -[]-> ()**.
- Example: Get all the movies where *Tom Hanks* acted in...

```cypher
MATCH (p: Person {name: 'Tom Hanks'} -[:ACTED_IN]->(m: Movie))
RETURN m.title
```

## Conditions

- The conditions can be set in the **WHERE** clause. 

```cypher
MATCH (m: Movie)
WHERE 2000 <= m.released <= 2003
RETURN m.title
```

- Sometimes we need to check if the property **is not null**.

```cypher
MATCH (p: Person)-[:ACTED_IN]->(m: Movie)
WHERE p.name='Jack Nicholson' AND m.tagline IS NOT NULL
RETURN m.title, m.tagline
```

- The **IN** sentence

```cypher
MATCH (p: Person)
WHERE p.born IN [1965, 1970, 1975]
RETURN p.name, p.born
```
