- Install APOC library
- Use the function `apoc.load.json(<filePath>)`

> [!IMPORTANT] 
> Remember to go to `Open Folder > Configuration` and create a file called `apoc.conf` with the following line: `apoc.import.file.enabled=true`.

## The `UNWIND` and `FOREACH` clauses

- They both are used to traverse lists.
- Unwind has more flexibility because allows the use of the `MATCH` clause inside of it.

## Avoid Repeated Nodes with `ON CREATE SET` and `ON MATCH SET`

- When using `MERGE` to create new nodes, if there cold be repeated nodes, add `ON CREATE SET` and `ON MATCH SET`.
- The following is show in the Example Query.

## Example Query

```cypher
CALL apoc.load.json($filePath) 
YIELD value 
UNWIND value.workbooks AS w 

// Merge the Workbook node
MERGE (workbook:Workbook {id: w.workbook_id}) 
    ON CREATE SET workbook.name = w.workbook_id, 
                  workbook.luid = w.workbook_project_luid
    ON MATCH SET  workbook.name = w.workbook_id, 
                  workbook.luid = w.workbook_project_luid

// Merge the Project node
MERGE (project:Project {id: w.workbook_project_luid})
    ON CREATE SET project.name = w.workbook_project, 
                  project.luid = w.workbook_project_luid
    ON MATCH SET  project.name = w.workbook_project, 
                  project.luid = w.workbook_project_luid

// Create relationship between Project and Workbook
MERGE (project)-[:HAS_WORKBOOK]->(workbook)

WITH w, workbook

// Merge the UpstreamTable nodes and relationships
UNWIND w.upstreamTables AS t
    MERGE (table:UpstreamTable {id: t.upstr_table_id})
        ON CREATE SET table.name = t.upstr_table_name, 
                      table.upstream_databases = t.upstreamDatabases
        ON MATCH SET  table.name = t.upstr_table_name, 
                      table.upstream_databases = t.upstreamDatabases
    MERGE (workbook)-[:USES_TABLE]->(table)

WITH w, workbook

// Merge the DataSource nodes and relationships
UNWIND w.upstreamDatasources AS d
    MERGE (data:DataSource {id: d.upstr_ds_id})
        ON CREATE SET data.name = d.upstr_ds_name, 
                      data.project = d.upstr_ds_project
        ON MATCH SET  data.name = d.upstr_ds_name, 
                      data.project = d.upstr_ds_project
    MERGE (workbook)-[:USES_DATASOURCE]->(data)

WITH w, workbook

// Merge the UpstreamFlow nodes and relationships
UNWIND w.upstreamFlows AS f
    MERGE (flow:UpstreamFlow {id: f.flow_id})
        ON CREATE SET flow.name = f.flow_name, 
                      flow.project = f.flow_project
        ON MATCH SET  flow.name = f.flow_name, 
                      flow.project = f.flow_project
    MERGE (workbook)-[:FLOWS]->(flow)
```

## Result

```cypher
MATCH (a)-[r :FLOWS|HAS_WORKBOOK|USES_DATASOURCE|USES_TABLE]-(b) 
RETURN a, r, b
```
