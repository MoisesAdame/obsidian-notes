## Relational Algebra
### Operations

| Symbol    | Name              |
| --------- | ----------------- |
| $\sigma$  | SELECT            |
| $\pi$     | PROJECT           |
| $\bowtie$ | INNER JOIN        |
| $\rtimes$ | SEMI JOIN         |
| $\times$  | CARTESIAN PRODUCT |

### Complexities
| Operation                             | Complexity          |
| ------------------------------------- | ------------------- |
| $\sigma$, $\pi$ (con duplicados)      | $O(n)$              |
| $\pi$ (sin duplicados), GROUP         | $O(n\cdot \log(n))$ |
| $\Join$, $\div$, $\cup$, $\cap$ y $-$ | $O(n\cdot \log(n))$ |
| $\times$                              | $O(n^2)$            |
