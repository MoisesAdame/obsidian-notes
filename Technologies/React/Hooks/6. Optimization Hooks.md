Hooks que **optimizan el renderizado** de la página, a través de evitar renderizar hooks que no lo necesitan.

Son dos:
1. `useMemo()`
2. `useCallback()`

## useMemo(calculateValue, dependencies)

### Generalidades

- Este hook proviene del concepto de **memoización**, e cual consiste en optimizar calculos guardando resultados de subrutinas costosas.
- Se guardan en cache aquellos cálculos que no es necesario repetir en cada render.
- **Parámetros:**
	- Primero, en *calculateValue*, se pasa una función pura que calcule un valor a guardar en cache.
	- Después, de forma obligatoria se el array de las *dependencies*, de las que depende calculateValue.
- **Retorno:**
	- Siempre regresa el valor de calculateValue, pero solo ejecuta la operación ya sea durante la primer renderización o usando algún valor de dependencies cambia.
- **Buenas Prácticas:**
	- Cuando la operación a realizar es muy lenta.
	- El valor que egresa es una dependencia de otro hook.
	- Generalmente, no siempre hay que usar `useMemo()`, checar [[2. Memoization]] para técnicas a utilizar.

### Código

```tsx
import React, { useMemo } from 'react';

const OptimizedComponent: React.FC () => {
	const complexValue = useMemo(
	    () => superTimeConsumingFunction(val1, va2)
	,[val1, val2]);

	return (
		<h1>
			The result is: {complexValue}
		<h1/>
	);
};
```
