Permiten al componente **conectarse y sincronizarse** con sistemas externos, mediante la ejecución de efectos secundarios.

Existe uno:
1. `useEffect()`
## useEffect(setup, dependencies?)

### Generalidades

- Permite sincronizar componente con sistemas externos mediante la declaración de efectos.
- **Parámetros:**
	- Primero ocupa una función *setup*, la cual es básicamente la lógica del efecto.
	- Luego, de forma opcional pide un array de *dependencies*, los cuales son valores usados en la función *setup*.
- **Retorno:**
	- Regresa `undefined`.
- **Buenas Prácticas:**
	- El tamaño de *dependencies* debe ser constante.
	- Llamar la función, justo antes del return del componente.

> [!WARNING]+
> Si *dependencies* no se especifica, `useEffect()` correrá indefinidamente (en cada render). Procurar agregar [].
> En **modo estricto**, `useEffect()` corre dos veces. La inicial y la de desarrollo.

### Código

```tsx
import React, { useState, useEffect } from 'react';

const Button: React.FC = () => {
  const [count, setCount] = useState<number>(0)

  useEffect(() => {
    setTimeout(() => {
      setCount((count) => count + 1);
    }, 1000);
  }, []);
  
  return (
    <h1>
      I've rendered {count} times!
    </h1>
  );
};
```
