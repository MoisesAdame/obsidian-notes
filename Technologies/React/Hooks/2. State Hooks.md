Permiten al componente **recordar** cierta información.

Existen dos:
1. ```useState()```
2. ```useReducer()```

## useState(initialState)

### Generalidades

- Agrega una variable de estado al componente.
- **Parámetros:** 
	- Puede ser un valor, entendiéndolo como el valor inicial.
	- Puede ser una función, la cual debe ser **pura** (sin argumentos y con un valor de retorno de cualquier tipo).
- **Retorno:**
	- Regresa un array con dos valores, los cuales son:
		1. El estado actual.
		2. La función *set*.
- **Buenas Prácticas:**
	- Deconstruir el array de retorno.
	- Usar el siguiente patrón ```[currentState, setCurrentState]```.

### Código

```tsx
import React, { useState } from 'react';

const SimpleInput: React.FC = () => {
  const [text, setText] = useState<string>('hello');

  function handleChange(e) {
    setText(e.target.value);
  }

  return (
    <>
      <input value={text} onChange={handleChange}/>
      <p>You typed: {text}</p>
      <button onClick={() => setText('hello')}>
        Reset
      </button>
    </>
  );
};
```
