Permiten a componente **recibir información** de padres, sin pasarla como **prop**.

Existe uno:
1. ```useContext()```

## useContext(someContext)

### Generalidades

- Nos permite leer y suscribirnos a cierto contexto.
- **Parámetros:**
	- El contexto que se creó en alguno de los padres con ```createContext()```.
- **Retorno:**
	- Regresa el valor de contexto el cual proviene del `SomeContext.Provider` más cercano.
- Cuando el valor de contexto cambia, React actualiza a los hijos del contexto.

### Código

```tsx
import React, { createContext, useContext } from 'react';

const ThemeContext = createContext<string | null>(null);

const App: React.FC = () => {
  return (
    <ThemeContext.Provider value="dark">
      <Button>Click me</Button>
    </ThemeContext.Provider>
  );
};

const Button: React.FC<IButton> = ({ children }) => {
  const theme = useContext(ThemeContext);
  const className = 'button--' + theme;
  
  return (
    <button className={className}>
      {children}
    </button>
  );
};
```
